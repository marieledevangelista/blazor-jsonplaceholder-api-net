# Blazor JSONPlaceholder API

Atividade da disciplina Usabilidade, Desenvolvimento Web, Mobile e Jogos.

Aplicação Blazor em .NET 10 que consulta `https://jsonplaceholder.typicode.com/users`, pega o primeiro usuário da lista e exibe nome, cidade e empresa. Também registra os dados no console do servidor.

## Como executar

1. Instale o SDK .NET 10.
2. No terminal, dentro da pasta do projeto, execute `dotnet run`.
3. Abra o endereço local indicado no terminal.

## Resultado esperado

- Nome: Leanne Graham
- Cidade: Gwenborough
- Empresa: Romaguera-Crona

O resultado depende da resposta atual da API.
